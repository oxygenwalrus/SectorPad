# Controller prompt artwork

Xbox Series Button Icons and Controls by Zacksly.
Source: https://zacksly.itch.io/xbox-series-button-icons-and-controls

Input Prompts by Kenney (https://kenney.nl/assets/input-prompts), CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/

SectorPad uses the supplied white-outline PNGs. Changes: transparent margins cropped, one transparent pixel added to guard texture filtering, and size/color/opacity applied at runtime. The illustrations and lettering are retained. Generic face prompts use Kenney positional button diagrams; Ally uses the matching Xbox-layout legends. The original individual PNGs, upstream archive checksums and source-path mapping are preserved in vendor/ui-art/prompts/sources.json. Full source archives are not required to regenerate the selected assets.

These assets are credited as community artwork; no hardware-vendor endorsement is implied.
